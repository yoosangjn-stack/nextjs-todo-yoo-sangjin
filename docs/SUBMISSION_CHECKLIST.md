# 실제 연동 및 제출 확인
작성자: 유상진

아래 항목은 아직 미검증입니다. 실제 결과를 확인한 뒤 체크합니다.

- [ ] Supabase 새 과제 프로젝트 스키마 적용 및 RLS 활성화
- [ ] 회원가입 후 이메일 인증, 로그인, 로그아웃
- [ ] 로그아웃 상태로 / 및 /todo/new 접근 시 로그인 이동
- [ ] 계정 A에서 항목 생성 → 새로고침 후 유지
- [ ] 제목·내용·상태 수정 → 새로고침 후 유지
- [ ] 삭제 취소 시 유지, 삭제 확인 시 목록에서 제거
- [ ] 계정 B에서 A의 상세 주소 접근 차단
- [ ] B의 인증 토큰으로 DB API를 직접 호출해 A의 조회·수정·삭제가 차단되는지 확인
- [ ] 빈 제목·긴 제목·잘못된 상태 값 차단
- [ ] 네트워크/DB 오류 시 성공으로 오인하지 않고 오류 표시
- [ ] Vercel 배포와 배포 환경변수 등록
- [ ] 배포 URL에서 동일한 시나리오 재실행
- [ ] 개인 GitHub 공개 URL 및 Vercel URL을 README/LMS에 기입
- [ ] 실제 화면을 캡처·녹화하고 파일 첨부

## 시연 순서
로그인 → 빈 목록 → 새 할 일 등록 → 상세 → 수정 및 완료 상태 → 새로고침 → 삭제 → 로그아웃 → 접근 차단.
개인 이메일, 인증 토큰, 환경변수, DB 비밀번호는 영상에서 노출하지 않습니다.
